# ♟️ AETHERIA: Sovereign Shatter Chess
**MADE BY SOU.** ([@sca4s](https://github.com/sca4s))

**AETHERIA** is a 3D Wizard's Chess web application built entirely inside a single HTML file (`Aetheria.html`) with zero external media assets. Powered by **Three.js (WebGL)**, a custom **FIDE-compliant Chess & Alpha-Beta AI Engine**, and a **Procedural Web Audio Synthesizer**, every capture triggers a choreographed arcane strike and shatters the defeated piece into dozens of 3D physics-driven stone fragments.

---

## ✨ Features

* **💥 Physics-Driven 3D Shatter Captures:** Capturing an enemy piece triggers an arcane wind-up, a violent lunge, and a 38+ shard polyhedral explosion with gravity, board-surface bouncing, and expanding shockwave rings.
* **🫧 Spatial Liquid Glass UI:** Frosted-glass HUD surfaces, specular highlights, a device-calibration launch modal, and a collapsible move chronicle.
* **🌍 7 Live-Switchable 3D Realms & Board Styles:**
  1. **Cathedral:** Gothic sanctuary with ribbed vault pillars, stained-glass god-rays, and floating embers.
  2. **Night Glade:** Full moon, glowing cyan runestones, and drifting fireflies.
  3. **Sunlit Day:** Open-air classical marble colonnade and drifting clouds.
  4. **Grass & Leaves:** 4,500+ instanced swaying 3D grass blades, forest trees, and tumbling leaves.
  5. **Ocean Waves:** Real-time vertex-displaced 3D rolling sea waves around a Reef Altar.
  6. **Deep Space:** Starfield dome, rotating nebula rings, and an orbiting asteroid belt.
  7. **Desert Sand:** Sculpted 3D golden sand dunes, pyramids, obelisks, and a sandstone-and-gold board.
* **📱💻 Adaptive Device Controls (Chosen at Launch):**
  * **Smartphone / Touch Mode:** Direct touch selection, 1-finger camera orbit, 2-finger pinch-to-zoom, and an on-screen **iOS 28 Glass D-Pad & Action Dock**.
  * **PC / Laptop Mode:** Mouse click/drag raycasting + a **3D Spatial Keyboard Cursor** (`WASD` / `Arrow Keys` to glide across squares, `Enter` / `Space` to select or confirm moves, `Q`/`E` to orbit, `1–7` to switch realms).
* **🧠 Full Chess Engine & Automaton AI:** Supports Castling (`O-O`, `O-O-O`), En Passant, Pawn Promotion (Rite of Ascension modal), Check/Checkmate/Stalemate detection, Standard Algebraic Notation (SAN) move history, Undo, 3 AI difficulty levels (*Novice*, *Adept*, *Archmage*), and *2-Player Pass & Play*.
* **🔊 Zero-Asset Procedural Audio:** Synthesizes stone sliding, rune chimes, arcane charge-ups, sub-bass shockwaves, and scattering rock debris in real time using the native Web Audio API.

## 🎮 Controls

### 💻 PC / Laptop (Mouse + Keyboard)
| Input | Action |
| :--- | :--- |
| **Left Click** | Select piece / Move to highlighted square |
| **Click + Drag / Scroll** | Orbit camera / Zoom in & out |
| **W, A, S, D** or **Arrow Keys** | Move 3D Spatial Board Cursor |
| **Enter** or **Space** | Select piece or confirm move at cursor |
| **Q / E** | Orbit camera Left / Right |
| **C** | Trigger instant **Strike Demo** (Shatter showcase) |
| **U** | Undo last move |
| **1 – 7** | Instant-switch between the 7 3D environments |

### 📱 Smartphone / Tablet (Touch)
| Input | Action |
| :--- | :--- |
| **Tap Square / Piece** | Select piece / Move to highlighted square |
| **1-Finger Drag** | Orbit camera around the board |
| **2-Finger Pinch** | Zoom camera in & out |
| **On-Screen Glass D-Pad** | Precision cursor navigation & one-tap confirm |
